# 02. Borrowing and References

Each exercise contains one small Rust issue. The embedded C++ program is correct and shows the intended behavior.

| # | Exercise | Concept |
|---:|---|---|
| 01 | `01_two_mutable_borrows.rs` | Exclusive mutable borrowing |
| 02 | `02_mutable_and_immutable.rs` | Mutable vs immutable borrow overlap |
| 03 | `03_borrow_parameter.rs` | Borrow instead of owning |
| 04 | `04_mut_parameter_binding.rs` | Mutable references permit mutation |
| 05 | `05_borrow_after_push.rs` | Vector reallocation and references |
| 06 | `06_split_mut_slice.rs` | Disjoint mutable borrows |
| 07 | `07_borrow_scope.rs` | Non-lexical lifetimes |
| 08 | `08_borrowed_temporary.rs` | Borrowing a temporary |
| 09 | `09_mutable_binding_needed.rs` | Binding mutability |
| 10 | `10_reborrow_mut.rs` | Reborrowing a mutable reference |
